3.1 Die Anwendung erstellt aus Daten, welche die Nutzenden bereitstellen (Kontoauszug, CSV‑Export oder manuelle Eingabe), eine Datei im Format eCH‑0196 (XML) und ein PDF mit Barcode zum Import in eine kantonale Steuersoftware. Zusätzlich zeigt sie eine Übersicht der Transaktionen.
